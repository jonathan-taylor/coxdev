coxdev API Reference
====================

API reference for the coxdev Python package. For worked examples and the
derivations, see the `coxdev documentation <../>`_. The R package has the
same interface, ``CoxDeviance$new(...)`` in place of ``CoxDeviance(...)``;
see ``?CoxDeviance`` in R.
